To sign in outside the chat, first quit your MCP client, such as Claude Desktop: the sign-in shown here holds the saved session until the server stops. Then run the Docker login viewer: docker run -it --rm -v ~/.linkedin-mcp:/home/pwuser/.linkedin-mcp -p 127.0.0.1:6080:6080 stickerdaniel/linkedin-mcp-server:latest --login --login-viewer, or on the host: uvx mcp-server-linkedin@latest --login
