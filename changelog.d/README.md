# Changelog fragments

A `feat`, `fix` or breaking (`type!:`) pull request adds one file here named
`<PR number>.<type>.md`, where `<type>` is `feat`, `fix` or `breaking`. It
holds one user-facing sentence without a PR link. The release bump folds every
fragment into `CHANGELOG.md`.

See [CONTRIBUTING.md](../CONTRIBUTING.md#changelog-fragments) for the steps.
