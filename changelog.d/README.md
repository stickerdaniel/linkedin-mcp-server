# Changelog fragments

A `feat`, `fix` or breaking (`type!:`) pull request adds one file here named
`<PR number>.<type>.md`, where `<type>` is `feat`, `fix` or `breaking`. It
holds one user-facing sentence without a PR link. Keep it to 90 characters,
one line on the release page. The release bump folds every fragment into
[`docs/CHANGELOG.md`](../docs/CHANGELOG.md).

See [CONTRIBUTING.md](../.github/CONTRIBUTING.md#changelog-fragments) for the steps.
